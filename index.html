01 Caso de estudio · PWA

Gestión de un club de natación

Caso de estudio de una PWA de gestión deportiva: planificación, asistencia, convocatorias y seguimiento de marcas. Incluye revisión técnica, una presentación visual de 15 s y una muestra de código aislada (normalización de tiempos) con seis pruebas automatizadas.

El código completo, las cuentas y los datos del club son privados. No es una demo interactiva pública.

02 Prototipo · IA

Claro · AI Learning Companion

Prototipo de estudio en español: entender un concepto, practicar con tres preguntas y saber qué repasar. Integra la API de Gemini a través de un endpoint de servidor e incluye lecciones preparadas que funcionan sin clave.

Funciona en local; una lección real generada con IA está verificada. El alojamiento público está pendiente, por eso no hay demo enlazada.

03 Automatización · Demo

Registro de visitas (flujo CRM)

Simulación en JavaScript con datos ficticios: valida y normaliza registros, detecta duplicados y propone tareas para una revisión humana. Incluye pruebas.
